# 回归基准与自测

仓库**不包含**任何 PCL 二进制，因此 CI 只做编译校验。功能回归请在本地用你自己的启动器执行。

## 基准哈希（官方原版 PCL2 2.99.0.0 / code 414）

原始文件：`5B64D6D540C376390470CEA3AB99D47661E8BCA81BE2BA647EA83E7D2E9428FA`（5,985,280 字节）

| 操作 | 期望结果 SHA256 | 修改点 |
| --- | --- | --- |
| `--unlock-only`（模式 1） | `BAAE85029FCE0BBDF737F9649F2AC6F886BED956D67FDA3EAFD9853DE611F5F3` | 3 处 / 54 字节 + 扩展 `.pclx` 段 512 字节 |
| `--block-update`（模式 2） | `F0571D7B4A865AFBD62E98F9349B6288B0522B4FBC476CD639AD520CEE3BA342` | 9 处 / 106 字节 + 扩展 `.pclx` 段 512 字节 |
| `--uninstall`（模式 3） | 回到原始 `5B64D6D5…`（5,985,280 字节） | 用 .bak 覆盖 |

模式 2 的 8 个等长修改点偏移：`0x2C79E(48B)`、`0x246B2(27B)`、`0x18396`、`0x628FD`、
`0x64142`、`0x692C4`、`0x6E400`、`0x329AA`。不同版本偏移会变，工具按语义定位、不写死偏移。

整合包安装恢复的改动点（同版本）：

- 新增段 `.pclx`：VA `0x5B8000`（不变），原始数据 `0x5B5200`（不变），大小 512 字节（内容 = 原重定位块副本 + 新方法体）。
- MethodDef 表 `ModpackInstall(String,String,String)` 的 RVA 字段：文件偏移 `0xB090C`，改为 `0x5B8010`。
- 方法体：875 字节代码 + 3 条异常子句；异常表三项 = 内层 finally `[0x143,0x276)`、
  catch `[0x6D,0x284)`、外层 finally `[0x27,0x35F)`，处理器 `[0x35F,0x369)`。

## 自测步骤

1. 备份一份官方启动器（推荐先复制到临时目录，不要动你正在用的那份）。
2. 先 dry-run：
   `PclUnlockPatcher.exe "C:\path\Plain Craft Launcher 2.exe" --dry-run`
   看它报告的"修改点数量"与"整合包安装：已恢复"，并确认没有报错。
3. 去掉 `--dry-run` 正式执行，比对输出里的 SHA256 与上表。
4. 运行启动器：下载 → 安装新游戏，版本列表应能加载；
   再把任意整合包 zip 拖进 PCL 窗口，应能正常识别类型并开始安装。
5. 用 `--uninstall` 还原，哈希应回到基准原版值。

## 已知差异说明

- 2.13.1.1（code 410）等旧版本本身没有下载限制，模式 1 会提示"无需注入"且不写入；
  模式 2 仍可打更新屏蔽（6 处），实机启动正常。这些版本同样会被植入 `.pclx` 段以恢复整合包安装。
- 资源站整合包详情页的一键安装按钮、资源页"安装已有整合包"按钮仍不可用（见 README 已知限制）。
- 若某版本定位失败，工具会打印具体原因并且不写入文件，此时可提 issue 附版本号。
